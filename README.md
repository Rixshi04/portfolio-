

# Rishi Kumar Portfolio

Next.js portfolio for Vercel.

## OriginKit Wire Terrain

The hero is styled to match the OriginKit **Wire Terrain** visual direction: black background, orange wireframe terrain, horizon sun, motion, and pointer steering.

For the official OriginKit source component, install it from the project root with:

```bash
bunx --bun originkit@latest add wire-terrain
```

Then place the generated component at `components/originkit/wire-terrain` and replace the local `WireTerrain` implementation in `app/page.tsx` with the generated component. The current repository remains self-contained and deployable without requiring that external component.

## Run

```bash
npm install
npm run dev
```

## Deploy

Import `Rixshi04/portfolio-` into Vercel and deploy as a Next.js project.
