# Rishi Kumar — Portfolio

Modern AI/ML-focused portfolio built with Next.js, React and TypeScript.

## Highlights
- Animated cloud-sky hero
- Responsive recruiter-friendly layout
- About, toolkit, projects, approach and contact sections
- AI/ML, computer vision and software engineering project showcase

## Run locally

```bash
bun install
bun dev
```

Open `http://localhost:3000`.

## Customize
Update the email, LinkedIn URL and project repository links in `app/page.tsx`.
